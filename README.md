# Porsche — Interactive Landing Page

A premium, Awwwards-inspired Porsche landing page built with **React**, **Vite**, **SCSS**, and **GSAP**. The project focuses on immersive animations, smooth scrolling, and a modern user experience while maintaining high performance.

## ✨ Features

* Modern and responsive design
* Smooth GSAP animations
* Smooth Scroll with Lenis
* Scroll-triggered interactions
* Optimized images and video
* Fully responsive layout
* Clean and scalable component architecture
* Fast development with Vite

## 🛠️ Tech Stack

* React
* Vite
* SCSS
* GSAP
* JavaScript (ES6+)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/porsche-landing-page.git
```

### Navigate to the project

```bash
cd porsche-website
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
